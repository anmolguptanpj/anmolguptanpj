### Vendor Performance Analysis & ETL Pipeline

**GitHub:** [Vendor_performance_analysis](https://github.com/anmolguptanpj/Vendor_performance_analysis)

A business analytics project based on large-scale vendor and inventory datasets, built from my real interest in operations and data-driven decision making.

**Highlights**

- Built an ETL pipeline for **2GB+ multi-source datasets**
- Used chunk-based ingestion to optimize memory usage and prevent database corruption
- Automated CSV extraction and loading into SQL workflows
- Performed advanced SQL analysis using joins, aggregations, CTEs, KPIs, profit margins, and stock turnover ratios
- Found that top vendors drove major purchase volume while maintaining weaker margins, leading to vendor diversification insights
- Delivered **15+ visualizations and dashboards** for business intelligence
